## 🚀 Proyectos destacados

### [Workflow Engine](https://github.com/OdellChacon/workflow-engine)
Motor de automatización tipo n8n sobre **Django + PostgreSQL**. Los flujos se definen como grafos `trigger → condición → acción` y se ejecutan en una cola de trabajos sobre Postgres con reintentos, backoff exponencial, dead-lettering e idempotencia.
- Workers concurrentes con `SELECT … FOR UPDATE SKIP LOCKED`: ningún job se procesa dos veces.
- Intérprete de expresiones propio (tokenizer + parser recursivo), sin `eval`.
- Secretos cifrados con Fernet, UI con HTMX + Alpine, despliegue en Render (web + worker).

`Python` `Django` `PostgreSQL` `HTMX` `Render`

### [Fuel Track](https://github.com/OdellChacon/FUELTRACK) — Telefónica Venezolana
Aplicación web para el control de consumo de combustible de los motogeneradores en las estaciones de telecomunicaciones de la región andina. Reemplazó el registro en planillas manuales.
- Modelo de datos en PostgreSQL para cargas por estación y seguimiento de consumo.
- Módulo de auditoría y vistas de consulta para el personal operativo.

`Python` `Django` `PostgreSQL` `TailwindCSS`

### [PMS Hotelería](https://github.com/OdellChacon/PMS_HOTELERIA)
Sistema de gestión hotelera: reservas, habitaciones, huéspedes, eventos, restaurante e inventario.
- Módulos separados por dominio (reservas, habitaciones, huéspedes, restaurante, inventario, empleados).
- Panel administrativo con reportes por reservas, huéspedes, empleados e inventario.

`Python` `Django` `JavaScript` `SQLite`

### [Sistema SARA](https://github.com/OdellChacon/SISTEMA_SARA) — UPTAIET
Control de asistencia docente, horarios y asignación de aulas para un instituto universitario. Automatizó una planificación que se armaba a mano cada período.

`Python` `Django` `JavaScript`
